=====================================================
Перенос базы:
=====================================================
Делаем логический дамп:
docker exec dash_db pg_dump -U postgres -d dash_config --schema=app --no-owner --no-acl > dash_config_dump.sql

Восстанавливаем:
docker cp dash_config_dump.sql dash_db:/tmp/
docker exec dash_db psql -U postgres -c "CREATE DATABASE dash_config;"
docker exec dash_db psql -U postgres -d dash_config -f /tmp/dash_config_dump.sql
