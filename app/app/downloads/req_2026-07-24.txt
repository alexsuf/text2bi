## Возможные интерпретации "баланса по регионам"

В зависимости от контекста бизнес-показателей, "баланс" может означать:

1. **Финансовый баланс** (прибыль/убыток по регионам)
2. **Нагрузку на инженеров** по регионам
3. **Количество заявок** по регионам

Рассмотрим SQL-запросы для каждого варианта:

## 1. Финансовый баланс по регионам

```sql
SELECT 
    r.name as region,
    SUM(f.revenue) as total_revenue,
    SUM(f.costs) as total_costs,
    SUM(f.revenue - f.costs) as profit
FROM finance f
JOIN clients c ON f.client_id = c.id
JOIN regions r ON c.region_id = r.id
GROUP BY r.name
ORDER BY profit DESC;
```

## 2. Нагрузка по регионам (количество заявок и часы)

```sql
SELECT 
    r.name as region,
    COUNT(sr.id) as total_requests,
    SUM(sr.duration_hours) as total_hours,
    AVG(sr.duration_hours) as avg_hours_per_request
FROM service_requests sr
JOIN service_objects so ON sr.object_id = so.id
JOIN clients c ON so.client_id = c.id
JOIN regions r ON c.region_id = r.id
WHERE sr.status = 'Закрыена'
GROUP BY r.name
ORDER BY total_requests DESC;
```

## 3. SLA выполнение по регионам

```sql
SELECT 
    r.name as region,
    COUNT(sr.id) as total_requests,
    SUM(CASE WHEN ms.sla_met = 1 THEN 1 ELSE 0 END) as sla_met_count,
    ROUND(AVG(ms.sla_met::numeric) * 100, 2) as sla_rate_percent
FROM service_requests sr
JOIN service_objects so ON sr.object_id = so.id
JOIN clients c ON so.client_id = c.id
JOIN regions r ON c.region_id = r.id
JOIN mart_sla ms ON sr.id = ms.id
WHERE sr.status = 'Закрыена'
GROUP BY r.name
ORDER BY sla_rate_percent DESC;
```

## 4. Используя аналитическую витрину mart_finance

```sql
SELECT 
    region,
    revenue,
    costs,
    profit,
    ROUND((profit / revenue) * 100, 2) as profit_margin_percent
FROM mart_finance
ORDER BY profit DESC;
```

## 5. Используя аналитическую витрину mart_region_load

```sql
SELECT 
    region,
    requests,
    hours,
    ROUND(hours / requests, 2) as avg_hours_per_request
FROM mart_region_load
ORDER BY requests DESC;
```
