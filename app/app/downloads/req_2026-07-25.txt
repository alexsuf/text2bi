Вопрос: регионы по степени sla
Ответ LLM: ## Регионы по степени SLA

Чтобы получить регионы, отсортированные по степени выполнения SLA, используйте аналитическую витрину `mart_sla_region`:

```sql
SELECT 
    region,
    sla_rate
FROM mart_sla_region
ORDER BY sla_rate DESC;
```

### Результат

| region | sla_rate |
|--------|----------|
| ... | ... |

### Пояснение

- **mart_sla_region** — аналитическая витрина, содержащая показатель выполнения SLA по регионам и месяцам
- **sla_rate** — доля заявок, выполненных в установленные нормативы (от 0 до 1)
- **ORDER BY sla_rate DESC** — сортировка от лучшего к худшему выполнению SLA

Если нужно посмотреть SLA по отдельным месяцам для каждого региона:

```sql
SELECT 
    region,
    month,
    sla_rate
FROM mart_sla_region
ORDER BY region, month DESC;
```
